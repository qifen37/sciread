# Contributing

SciRead welcomes focused contributions.

Please keep changes small and evidence-grounded. New domain profiles or Gold Notes should include:
- a clear task definition;
- author-supported contributions;
- source provenance;
- explicit handling of missing information;
- strong-claim calibration;
- no invented datasets, hardware, case studies, or mechanisms.

Before opening a pull request, run:

```bash
python scripts/validate.py
```

For major benchmark changes, document the source and explain whether the paper was used for development or only evaluation.
