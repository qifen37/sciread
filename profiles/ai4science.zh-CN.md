# AI4Science 专项 Profile

适用于依赖科学知识、机制、模拟或异构证据的科学机器学习论文。

重点核对：
- Predictive / Generative / Retrieval / Simulation 任务；
- 科学对象是什么；
- 数据是否稀疏、噪声、部分可观测；
- 使用哪些知识源与工具；
- IID / OOD；
- Temporal / Unseen Entity；
- Simulation 与 Experimental Validation。

必须区分：
- 预测性能；
- 机制合理性；
- 数据库/文献支持；
- 因果有效性；
- 实验验证。

不能互相替代。
