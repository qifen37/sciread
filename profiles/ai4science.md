# AI4Science Profile

Use with `SKILL.md` for scientific ML papers whose claims depend on scientific knowledge, mechanisms, simulations, or heterogeneous evidence.

Check:
- predictive vs generative vs retrieval vs simulation task;
- scientific object being modeled;
- data scarcity/noise/partial observability;
- knowledge sources and tools;
- in-distribution vs OOD generalization;
- temporal/unseen-entity transfer;
- simulation vs experimental validation.

Separate:
- predictive performance;
- mechanistic plausibility;
- database/literature support;
- causal validity;
- experimental validation.

Do not infer one from another.
